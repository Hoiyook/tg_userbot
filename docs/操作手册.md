# TG Userbot 操作手册

> 本文档是全部指令的统一归集（2026-09-25 全面盘点）。指令在 bot 对话与
> Saved Messages（收藏夹）都可执行；发任意文本给 bot 即打开按钮菜单。
> 快捷指令：发 `1` = `/cmdhis`（映射表在 config.COMMAND_SHORTCUTS，可扩展）。

## 〇、按钮菜单（2026-09-27 两级布局）

一级 5 行：`📊 总览｜📈 实时进度`、`📥 下载中心｜🔍 找文件`、
`🐾 Pawchive｜📡 标签监听`、`🌐 Chrome｜📋 白名单`、`⚙️ 设置｜🛠 高级工具`。
📥 下载中心 = 当前下载/队列/待重试/最近完成；⚙️ 设置 = 并发/去重/Cookie/
Caption/CD2/SQL模板；📊 台账与 📜 记录在 🛠 高级工具内。

## 二、下载与媒体（自动行为）

- 媒体（文件/图片/视频）发进或转发进 Saved Messages → 自动下载。
- 白名单 chat 收到媒体 → 自动转发进收藏夹下载（保留副本）。
- **目录模式标注**：转发媒体前后 5 秒内发评论 `/子目录#标注` →
  落 `原目录/子目录/` 且文件名带 `#标注`；只发 `/子目录` 则只落目录；
  普通评论仍拼文件名（原语义）。
- **抖音 / Instagram**：分享链接发进收藏夹 → 自动转解析 bot，回复视频自动下载。
- **重复媒体去重**：`/dedup` 查看状态，`/dedup off` 关闭（重下已删文件时用）。
- **并发**：`/thread` 查看；`/thread 5` 设置（3-20，每条各占独立连接）。

## 三、外链台账

- 直接发 `链接 备注` → 登记（默认 PENDING 未处理；重发同链接+新备注更新备注）。
  发送时自动查重：命中台账历史或 Pawchive 已完成外链会提示。
- `/links` — 未处理清单（带 ✅ 完成按钮）
- `/links 关键词` — 按备注/链接搜索（含已完成）
- 🌐 按钮 — 在 Chrome 可见打开（网盘链接带登录态）

## 四、Pawchive（/paw 全部子命令）

> 2026-09-25 起子命令统一为下划线标准形（/paw_plan），旧空格写法（/paw plan）继续兼容。

| 指令 | 说明 |
|---|---|
| `/paw`（=`/paw status`） | 状态总览：状态计数、失败帖画像（可重投/纯死链）、Cookie 健康、扫描进度、时间下限 |
| `/paw_progress <作者名>` | 按作者处理进度：状态计数/完成率/文件产出（死链与可重投分列）/待处理明细 |
| `/paw_plan <作者名> [all]` | 扫描作者入队（默认只收未收藏帖，需 Cookie） |
| `/paw_plan <作者名> since <YYYY-MM-DD> [all]` | 只收该日期之后的帖子 |
| `/paw_search <关键词>` | 搜作者（结果为按钮，点选即扫） |
| `/paw_post <URL\|帖子ID>` | 单独获取指定帖子（已入库失败帖则重投） |
| `/paw_att <URL\|ID\|行id>` | 帖子附件与外链状态清单 |
| `/paw_pr <URL\|ID\|行id>` | 帖子执行详情报告（统计/逐附件/外链/落盘实况） |
| `/paw_find <关键词>` | 按名称查扫描记录与当前目录文件 |
| `/paw manual` | 待人工帖工作台（外链清单 + ✅ 按钮） |
| `/paw_manual export` | 全部待处理外链导出为工作清单 |
| `/paw_done <行id \| 起-止 \| 作者名>` | 外链处理完标记 COMPLETED（如 `/paw done 105-120`） |
| `/paw_fail` | **非死链**失败明细（429/超时等可救项；404 死链不占版面） |
| `/paw_retry <行ID>`、`/paw_retry all` | 失败帖重投（all 自动跳过纯死链帖） |
| `/paw archive` | 归档明细（总数/按作者/最近条目含原帖地址） |
| `/paw_archive failed` | 把 FAILED 死链帖批量归档（含可恢复文件的保持 FAILED） |
| `/paw_archive_del <行id \| 起-止>` | 彻底删除归档帖（不可逆，只吃 ARCHIVED） |
| `/paw_since <YYYY-MM-DD \| off>` | 设默认时间下限（plan 未显式给 since 时自动应用） |
| `/paw_pause` / `/paw_resume` | 暂停/恢复下载 worker |
| `/paw_cookie <Cookie>` | 保存站点会话 Cookie（用于收藏对比；🧪 校验按钮可验证） |
| `/paw_csv [作者名]` | 导出直链清单 CSV 发到收藏夹 |
| `/paw_notify on\|off` | 帖子开始/完成通知开关（默认开；批量扫描嫌吵可关） |
| — | MANUAL 帖通知自带行id/发布日期与 ✅ 关账按钮（点击即 /paw_done） |

数据表说明见 `/help2`；非死链失败与死链的口径：错误以
`站点缺文件(404)` 开头 = 死链（重投无意义），其余（429/超时/SSL）可救。

## 五、Chrome 下载

- `/chrome <URL>` — 智能分流：文件直链 → 自动下载；网盘页（MEGA/Google盘/
  OneDrive/百度盘/夸克/115 等）→ 在日常 Chrome 可见窗口打开（带登录态）。
- `/chrome <子目录>/[#标注] <URL>` — 同目录模式标注语义。
- `/chrome_start` / `/chrome_stop` — Agent 启停（专用无头 Chrome 实例）。
- `/chrome_status` — Agent 状态；`/chrome_tasks` — 可取消任务列表。
- `/chrome_cancel 序号` — 取消任务（菜单里每条任务有 🛑 按钮，更直接）。
- 结果自动通知到控制面板；文件落 `下载目录/TG Chrome Download/`。

## 六、命令行 / 上传 / 模板

- `/sh` — 用法说明；`/sh <命令>` — 执行 shell（黑名单拦截高危操作，
  工作目录记忆）；`/sh cd <目录>` — 切换工作目录。
  ls 输出自动带目录按钮（点击进入）。
- `/up <路径>` — 上传文件到收藏夹（相对路径基于 /sh 工作目录，支持 ~）。
- `/cmdt` — 命令模板列表；`/cmdt_add <名字> <命令>` — 保存（同名覆盖）；
  `/cmdt_del <名字>` — 删除；`/cmdt_run <名字>` — 执行（走 /sh 全套纪律）。
- 快捷指令：发 `1` = `/cmdhis`。
- 消息历史：发给 bot 的文本自动记录（≤50 条，敏感输入窗口与程序面板除外）。

## 七、SQL

- `/sql <一条SQL>` — 诊断控制台：直接查/修 runtime DB（查询最多显示 N 行；
  写语句立即生效无撤销；勿对大表做无 LIMIT 笛卡尔积）。
- `/sqlt` — 模板列表；`/sqlt_add <名字> <SQL>` — 保存；`/sqlt_del <名字>` — 删除；
  `/sqlt <名字>` — 执行模板。

## 八、标签监听

- `/listen` — 状态与规则列表。

  目标可用 me（收藏夹）/@用户名/数字 ID；省略则只转发收藏夹。
- `/listen_edit <序号>` — 重新走一遍向导修改；`/listen_del <序号>` — 删除。

- 失败说明：聊天级失败不丢消息（checkpoint 不动，恢复后自动补扫）。
- `/listen_failed` — 失败任务明细；`/listen_retry <行id>` — 重试。

## 十二、CD2（CloudDrive2）

菜单 ☁️ CD2 子面板：🔴 实时状态（backup_status.json，分钟级）、启动/停止、🗂 备份记录（逐文件日志）、🔍 115 对账、启动/停止。
CD2 语义：媒体备份到 115 完成即删本地源；`/cd2ck` 找出的滞留 =
竞态漏备候选，需在 CD2 应用内对相应目录手动补扫。

## 十三、B站排队与目录解压

**B站排队（2026-11-03）**：合集在跑时新发的 /bili 链接**自动排队**
（单待办队列最多 5 条，重复链接不重复排），当前任务结束（完成/失败/停止）
后自动开始第一个。`/bili stop` 只停当前、队列保留；`/bili` 裸命令可看
队列。队列也在 app 看板总览实时可见（排队标签行）。

## 十四、目录解压（/extract）

| 指令 | 说明 |
|---|---|
| /extract <子目录> [dry] | 递归解压下载目录内子目录下的压缩包到**同名文件夹**（foo.zip → foo/）；**解压成功才删压缩包**，失败/需密码/损坏一律保留；dry=只预览；后台执行，完成通知进控制面板 |

路径相对下载目录（也接受**数据卷内绝对路径**）；支持 zip/rar/7z/tar 系
与 **7z 分卷**（.7z.001 入口，成功删全组）。安全规则：同名目录已有内容跳过
（幂等）、路径穿越拒绝、解压总量超「磁盘余量−2GB」跳过、半成品跳过、
单包失败不中断整轮。同一时间一个解压任务（串行）。

**回填范围**：/paw backfill 与定期轮巡**默认只回填最近 3 个月**发布的帖子
（不做全量扫描）；/paw_plan 扫描不受此限制（由 since 参数控制）。

**密码自动尝试**（候选链按序逐个试，第一个解开的获胜；/extract 与 /115x 共用同一链）：
1. /115x 场景：压缩包所在**目录名**（既有规则，最先试）
2. 压缩包文件名规则：最后一个 # 后的内容是密码（`合集#备注#zxc.zip` → zxc）
3. 同目录密码提示文件（文件名含 密码/password 的 .txt）：**文件名 stem**
   （密码zxc.txt → zxc，内容可 0 字节）
4. 该提示文件的**内容**（「密码是：xxx」→ xxx）
全部解不开 → 原包保留并在通知里列尝试过的密码。加密 zip（含 AES-256）经
p7zip（/extract）或 bsdtar（/115x）解——两者都支持 AES。

## 十四、目录解压（/extract）扩展说明

app 看板「回填」页新增**执行情况与执行记录**：当前状态（作者总数/游标/节奏）、
下一批作者（预计时间，逾期如实标注）、每轮执行记录（时间/作者数/摘要/游标，

## 十五、asmr-300 音声下载（/asmr）

| 指令 | 说明 |
|---|---|
| `/asmr <作品页链接\|RJ号\|数字id> [only 关键词]` | 入队下载整部音声作品（元数据+文件树走代理拉 API，逐文件断点下载）→ 115 `声音/asmr/RJ号/`，目录树原样还原 |
| `/asmr` | 队列状态（各状态计数 + 最近任务 + 进度） |
| `/asmr retry <RJ号\|all>` | 重投失败 |
| `/asmr del <RJ号>` | 移除任务（已落盘文件不动） |
| `/asmr stop` / `/asmr start` | 暂停 / 恢复领取（在途跑完） |

- 例：`/asmr https://www.asmr-300.com/work/RJ01207846`；`/asmr RJ01207846 only 含SE`（多版本作品只下一版，关键词对文件路径子串匹配）。
- RJ 主键判重（重复发链接直接回执已有）；幂等续跑（同名同尺寸文件跳过，重启/重投接着传）；完成通知含文件数/总大小/115 位置。
- API 域名可配置：`tg_secrets.json` 的 `asmr.api_base`（默认 `https://api.asmr-200.com`）或环境变量 `TG_ASMR_API`（优先级更高，重启生效）——镜像换域名时改这里即可，文件直链不受影响。
