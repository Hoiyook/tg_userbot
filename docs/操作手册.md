# TG Userbot 操作手册

> 本文档是全部指令的统一归集（2026-09-25 全面盘点）。指令在 bot 对话与
> Saved Messages（收藏夹）都可执行；发任意文本给 bot 即打开按钮菜单。
> 快捷指令：发 `1` = `/cmdhis`（映射表在 config.COMMAND_SHORTCUTS，可扩展）。

---

## 一、监控与查询

| 指令 | 说明 |
|---|---|
| `/status` | 运行状态（连接健康灯、保存目录、日志路径） |
| `/stats` | 台账：今日转发/解析/成功/失败汇总 |
| `/stats 3` | 最近 3 天台账（上限 7 天 = 日志保留期） |
| `/progress`（=`/downloading`） | 进行中下载的实时进度 |
| `/done` | 最近 10 条下载记录 |
| `/done 20` | 最近 20 条 |
| `/done 关键词` | 模糊匹配下载记录 |
| `/done 20 关键词` | 最近 20 条中模糊匹配 |
| `/find 关键词` | 媒体下落三源查询（队列/待重试/历史，忽略大小写字段子串） |
| `/queue` | 下载队列视图 |
| `/queue del 序号` | 从队列移除任务（执行中的先取消在途下载再移除） |
| `/retry` | 待重试列表（分页按钮） |
| `/retry 序号` | 单条重放 |
| `/retry all` | 全部重放（次数上限已取消；死文件由熔断兜底） |
| `/retry del 序号` | 从待重试列表移除 |
| `/usage` | 功能使用统计（累计｜近7天｜最后使用） |
| `/cmdhis` | 最近命令行（新→旧 ≤50 条，代码块整块可复制） |
| `/folder` | 保存目录 |
| `/logpath` | 日志路径 |

## 二、下载与媒体（自动行为）

- 媒体（文件/图片/视频）发进或转发进 Saved Messages → 自动下载。
- 白名单 chat 收到媒体 → 自动转发进收藏夹下载（保留副本）。
- **目录模式标注**：转发媒体前后 5 秒内发评论 `/子目录#标注` →
  落 `原目录/子目录/` 且文件名带 `#标注`；只发 `/子目录` 则只落目录；
  普通评论仍拼文件名（原语义）。
- **抖音 / Instagram**：分享链接发进收藏夹 → 自动转解析 bot，回复视频自动下载。
- **重复媒体去重**：`/dedup` 查看状态，`/dedup off` 关闭（重下已删文件时用）。
- **并发**：`/thread` 查看；`/thread 5` 设置（3-20，每条各占独立连接）。

## 三、外链台账

- 直接发 `链接 备注` → 登记（默认 PENDING 未处理；重发同链接+新备注更新备注）。
  发送时自动查重：命中台账历史或 Pawchive 已完成外链会提示。
- `/links` — 未处理清单（带 ✅ 完成按钮）
- `/links 关键词` — 按备注/链接搜索（含已完成）
- 🌐 按钮 — 在 Chrome 可见打开（网盘链接带登录态）

## 四、Pawchive（/paw 全部子命令）

| 指令 | 说明 |
|---|---|
| `/paw`（=`/paw status`） | 状态总览：状态计数、失败帖画像（可重投/纯死链）、Cookie 健康、扫描进度、时间下限 |
| `/paw plan <作者名> [all]` | 扫描作者入队（默认只收未收藏帖，需 Cookie） |
| `/paw plan <作者名> since <YYYY-MM-DD> [all]` | 只收该日期之后的帖子 |
| `/paw search <关键词>` | 搜作者（结果为按钮，点选即扫） |
| `/paw post <URL\|帖子ID>` | 单独获取指定帖子（已入库失败帖则重投） |
| `/paw att <URL\|ID\|行id>` | 帖子附件与外链状态清单 |
| `/paw pr <URL\|ID\|行id>` | 帖子执行详情报告（统计/逐附件/外链/落盘实况） |
| `/paw find <关键词>` | 按名称查扫描记录与当前目录文件 |
| `/paw manual` | 待人工帖工作台（外链清单 + ✅ 按钮） |
| `/paw manual export` | 全部待处理外链导出为工作清单 |
| `/paw done <行id \| 起-止 \| 作者名>` | 外链处理完标记 COMPLETED（如 `/paw done 105-120`） |
| `/paw fail` | **非死链**失败明细（429/超时等可救项；404 死链不占版面） |
| `/paw retry <行ID>`、`/paw retry all` | 失败帖重投（all 自动跳过纯死链帖） |
| `/paw archive` | 归档明细（总数/按作者/最近条目含原帖地址） |
| `/paw archive failed` | 把 FAILED 死链帖批量归档（含可恢复文件的保持 FAILED） |
| `/paw archive del <行id \| 起-止>` | 彻底删除归档帖（不可逆，只吃 ARCHIVED） |
| `/paw since <YYYY-MM-DD \| off>` | 设默认时间下限（plan 未显式给 since 时自动应用） |
| `/paw pause` / `/paw resume` | 暂停/恢复下载 worker |
| `/paw cookie <Cookie>` | 保存站点会话 Cookie（用于收藏对比；🧪 校验按钮可验证） |
| `/paw csv [作者名]` | 导出直链清单 CSV 发到收藏夹 |

数据表说明见 `/help2`；非死链失败与死链的口径：错误以
`站点缺文件(404)` 开头 = 死链（重投无意义），其余（429/超时/SSL）可救。

## 五、Chrome 下载

- `/chrome <URL>` — 智能分流：文件直链 → 自动下载；网盘页（MEGA/Google盘/
  OneDrive/百度盘/夸克/115 等）→ 在日常 Chrome 可见窗口打开（带登录态）。
- `/chrome <子目录>/[#标注] <URL>` — 同目录模式标注语义。
- `/chrome_start` / `/chrome_stop` — Agent 启停（专用无头 Chrome 实例）。
- `/chrome_status` — Agent 状态；`/chrome_tasks` — 可取消任务列表。
- `/chrome_cancel 序号` — 取消任务（菜单里每条任务有 🛑 按钮，更直接）。
- 结果自动通知到控制面板；文件落 `下载目录/TG Chrome Download/`。

## 六、命令行 / 上传 / 模板

- `/sh` — 用法说明；`/sh <命令>` — 执行 shell（黑名单拦截高危操作，
  工作目录记忆）；`/sh cd <目录>` — 切换工作目录。
  ls 输出自动带目录按钮（点击进入）。
- `/up <路径>` — 上传文件到收藏夹（相对路径基于 /sh 工作目录，支持 ~）。
- `/cmdt` — 命令模板列表；`/cmdt add <名字> <命令>` — 保存（同名覆盖）；
  `/cmdt del <名字>` — 删除；`/cmdt run <名字>` — 执行（走 /sh 全套纪律）。
- 快捷指令：发 `1` = `/cmdhis`。

## 七、SQL

- `/sql <一条SQL>` — 诊断控制台：直接查/修 runtime DB（查询最多显示 N 行；
  写语句立即生效无撤销；勿对大表做无 LIMIT 笛卡尔积）。
- `/sqlt` — 模板列表；`/sqlt add <名字> <SQL>` — 保存；`/sqlt del <名字>` — 删除；
  `/sqlt <名字>` — 执行模板。

## 八、标签监听

- `/listen` — 状态与规则列表。
- `/listen on` / `/listen off` — 总开关。
- `/listen add <聊天> <标签> [目标,目标] [on|off]` — 新增规则
  例：`/listen add @source #01musume me,@speedlearnnn on`
  目标可用 me（收藏夹）/@用户名/数字 ID；省略则只转发收藏夹。
- `/listen edit <序号>` — 重新走一遍向导修改；`/listen del <序号>` — 删除。
- `/listen interval <分钟>` — 扫描周期；`/listen scan` — 立即扫描。
- 失败说明：聊天级失败不丢消息（checkpoint 不动，恢复后自动补扫）。

## 九、白名单

- `/wl` — 列表（含扫描进度）。
- `/wl add <ID或@用户名>` — 加入（也可回复转发消息后 `/wl add`）。
- `/wl del <ID或序号>` — 移出。
- `/wl scan` — 立即扫描一轮。
- `/wl since <序号|@用户名|ID> <消息id>` — 回补停机漏掉的存量。

## 十、Caption 清洗

- `/caption_filter` — 规则列表。
- `/caption_filter add <规则>` — 添加（`field:作者`、`regex:https?://\S+`）。
- `/caption_filter del <序号>` — 删除；`/caption_filter test <原文>` — 试清洗。

## 十二、CD2（CloudDrive2）

菜单 ☁️ CD2 子面板：启动/停止、备份记录、🔍 115 对账。
CD2 语义：媒体备份到 115 完成即删本地源；`/cd2ck` 找出的滞留 =
竞态漏备候选，需在 CD2 应用内对相应目录手动补扫。
